# Azura Water Sim Plugin

This plugin is an optimised version of the UnityOceanWavesAndShip plugin realized by DitzelGames. The original code is great, but using it I noticed that it wasn't really suited for large water surfaces, it broke quickly and is not very optimised for surface larger than a few meters. So I released my own modified version of this plugin which aim to make it work flawlessly for very large water surface by partitionning the simulation in smallers chunks.
Check out the original code here : https://github.com/ditzel/UnityOceanWavesAndShip
